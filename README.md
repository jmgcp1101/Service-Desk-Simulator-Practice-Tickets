# 🛠️ Service Desk Simulator — IT Troubleshooting Practice

> **Learning IT support by actually troubleshooting problems — one ticket at a time.**

This repository contains my hands-on practice with **IT support, troubleshooting, networking, system administration, and user access issues** using the Service Desk Simulator.

Instead of simply collecting certificates or adding random projects to my portfolio, I wanted to build something that lets me **practice how an IT support engineer actually thinks**:

**Read the ticket → Understand the symptoms → Investigate → Test → Troubleshoot → Resolve → Learn from it.**

Each ticket represents a different technical problem, and I document not only how I solved it, but also where I got stuck, what I initially overlooked, and what I learned from the process.

---

## 🎯 Why I Built This

I'm working toward a career in **Cybersecurity and Network Engineering**, while continuing to strengthen my foundation in **networking, systems, and IT infrastructure**.

One thing I've realized is that technical knowledge is only useful if I can actually apply it when something breaks.

That's why I created this repository.

The goal isn't to pretend that I already know everything.

The goal is to **practice troubleshooting different types of technical problems and become better at figuring things out when I don't immediately know the answer.**

Some tickets are straightforward.

Some require looking at the problem from a different angle.

And some made me realize that I was looking in the wrong place entirely. 😂

That's part of the learning process.
